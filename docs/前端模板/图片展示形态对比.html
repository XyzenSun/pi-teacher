  • 图必然可见：不依赖模型写对 Markdown，展示指令由工具 details 通道结构化下发。
  • 位置固定：图钉在工具调用处，历史重载、SSE 流式两条路径渲染一致。
  • 图与正文分离：阅读顺序是「工具卡 → 图 → 讲解」，图不嵌在行文里。
  • 大图占屏：一屏一张 480px 图，连续多图时纵向拉得很长。

  • 位置随模型排版漂移：同一张图每次生成的位置可能不同。

图已生成，点缩略图可以放大看细节。牛顿手里的苹果、树影和月光都画进去了。

  • 省空间：150px 缩略图一行一张，多图场景可横向排成条。
  • 想看再放大：灯箱在原位覆盖展开，不打断阅读位置。
  • 多一层交互：看图必须多点一下（学习场景里图常是「记忆锚点」，多半还是要放大看）。
  • 灯箱是新前端组件：遮罩、关闭、Esc 键、滚动锁，实现面比 A 大。

↑ 缩略图真的可以点：会弹出灯箱预览，点击遮罩关闭。
