# pi-web 文件索引

> 用途：以后要查某个功能怎么实现，直接在这份索引里定位文件，不用重新翻仓库。
> 仓库：https://github.com/agegr/pi-web ｜ MIT ｜ 本地克隆 `/tmp/pi-web` ｜ 快照 commit `8aec7a1`（2026-09-05）
> 规模：TS/TSX 约 62500 行（不含 node_modules），Next.js 16 App Router + React 19 + Tailwind 4
> 依赖 Pi：`@earendil-works/pi-*@0.84.3` 固定版（我们本机 0.84.2）

## 价值标记说明

| 标记 | 含义 |
| --- | --- |
