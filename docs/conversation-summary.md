# 当前对话摘要

## 目标

设计一个基于开源 Agent SDK 的 Web 学习助手。用户希望把主要精力放在学习业务流程、分类型任务驱动和长期学习机制上，而不是重复实现成熟 Agent 底层能力。

## 已确认决策

1. Agent 底座使用 `earendil-works/pi`（Pi Agent Harness），不再研究 DeepSeek Harness。
2. 采用全栈 TypeScript，因为 Pi SDK 以 TypeScript 为主，可以直接嵌入 Node 后端。
3. Pi 负责 Agent Loop、流式对话、tool calling、工具调用循环和自动上下文压缩。
4. 产品只做 Web UI，不做终端对话。Pi 没有官方交互式 Web UI，前端需要自行实现。
5. workspace 是持久化学习主题容器；一个 workspace 可以有多场 session。
6. 一场完整的多轮对话对应一个 Pi session，不是一条用户消息对应一个 session。
7. 默认一场对话一个 session；跨 session 的连续性通过 workspace 的持久化数据和 briefing 重建。
8. 会话历史必须在 Web UI 中完整可见。Pi 自动压缩只影响模型上下文，不影响历史展示。
9. session 需要支持 Pi 自动生成标题，也要能在 Web UI 修改标题。
10. `type` 挂在 workspace：`short-term` 不进入复习计划且不制卡；`long-term` 才维护卡片与复习状态。
11. 长期 workspace 里偶尔出现与目标无关的问题，不影响整体目标，也不应因此制卡。
12. 短期学习可以升级为长期：凝结笔记、难题、重要结论等学习结果导入新的或已有的长期 workspace，并自动执行制卡流程。
13. 长期学习可以包含面试八股文、算法题等；问题/任务可作为卡片，参考答案或评价标准作为卡片背面/辅助内容，AI 负责解读用户回答。
14. 复习使用 FSRS 作为调度基线，优先使用 `ts-fsrs`，而不是嵌入完整 Anki 或依赖 AnkiConnect。
15. AI 负责评价开放式回答；FSRS/代码负责计算 due date 和卡片状态。AI 允许提出特殊覆写请求，但不由 AI 自由拍日期。
16. 错误回答判 `Again`；答对但吃力才是 `Hard`，不能简单把 0-100 分线性映射到四档。
17. 只有长期 workspace 才触发制卡提醒。普通学习不制卡。
18. 卡片采用 AI 提议方向，具体确认 UI 仍待讨论。
19. 用户偏好手写为主，AI 可以提议，但需要用户确认才生效。
20. 长期记忆任务和偏好更新任务都可通过 Hook 周期性提醒模型；不需要在普通回复里汇报“已检查”。
21. 用户偏好提醒频率较慢，暂定每 30 轮。
22. 如果偏好提醒和制卡提醒同时触发，合并成一条内部提醒，让模型判断是否处理。
23. 扩展能力不全部采用同一种插件形式：Skill 适合模型行为指令，MCP 可留作跨 harness 外部能力，Pi Extension 用于 Loop 生命周期、Hook、上下文和高权限能力，确定性业务逻辑使用普通应用模块与结构化 tool。
24. 默认内容格式为 Markdown。
25. HTML 是可选能力，后续实现；需要向用户说明会消耗更多 Token，并增加服务端渲染和安全处理成本。
26. Mermaid 与 AI 生图并存：Mermaid 适合结构化图，AI 生图适合具象对象和视觉记忆辅助。
27. 首版优先做好 Markdown + AI 生图；AI 生图本身是可选项，不是所有知识点都强制生成。
28. 业务确定性数据需要持久化。方向是 Pi 管会话，应用数据库管 workspace、卡片、FSRS 状态、review logs、摘要和偏好；SQLite 是单用户场景的优先候选，但最终数据库方案仍未定。

## 已讨论但未最终决定

- 卡片提议是否在会话结束统一确认，还是实时显示候选并允许逐项确认。
- 一场复习是逐卡问答、topic 分组对话，还是两者并存。
- 主 Agent 如何做人机接口，代码如何确定性生成今日复习队列。
- Pi 默认 JSONL 会话后端与官方 SQLite session backend 的具体选择。
- 应用数据库 schema 和 Pi session metadata 的字段设计。
- 生图服务、模型、预算、图片存储和失败重试。
- 后端/前端框架。

## 讨论中的重要设计原则

- 压缩是模型运行时的有损上下文视图，不是业务数据存储策略。
- 确定性数据和确定性操作使用代码与结构化 tool，不依赖自然语言解析。
- 灵活的教学行为交给模型、Skill 和可配置策略；不会把所有东西都硬编码成独立模式。
- 不为了“插件化”而为只有一个实现的东西过早制造复杂动态接口。
- 视觉产物应按场景选择：结构关系优先 Mermaid，具象记忆辅助才使用扩散模型生图。
