# 学习期限挂在学习空间上，而不是会话上

> Status: 已被 [ADR-0013](0013-new-study-type-supersedes-0002.md) 取代。「短期 / 长期空间」的划分已废止，改为学习与复习两类活动 + 空间级制卡倾向。以下内容仅作历史记录。

短期与长期是学习主题的属性，不是某一场对话的属性。同一个长期主题下的每场对话都应当受同样的复习约束，而用户在长期空间里临时问一个无关问题，也不应该因此改变主题的性质。因此 `short-term / long-term` 挂在 Workspace 上，会话不携带自己的学习期限。

## Consequences

- 是否制卡、是否注入卡片提醒，只看所属空间的类型，判断点唯一。
- 长期空间中的无关闲聊仍可能被模型误判为值得制卡，这要靠提示词约束和用户确认兜底，而不是靠会话级开关。
- 短期学习成果要进入复习计划，只能通过升级动作迁入长期空间，没有中间态。
- 不支持长期空间降级为短期空间：降级会让已有卡片和复习历史失去归属，且没有真实需求。
