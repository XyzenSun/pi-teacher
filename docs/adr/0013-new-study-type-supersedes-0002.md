# 制卡倾向挂在学习空间上（取代 ADR-0002）

> Status: 取代 [ADR-0002](0002-learning-horizon-on-workspace.md)

ADR-0002 曾把学习期限（`short-term` / `long-term`）挂在学习空间上，并规定只有长期空间才制卡。该模型现已废止，原因是它把两件不同的事混为一谈：**「这件学习任务要持续多久」与「这场学习要不要沉淀卡片」并不等价。**

新模型是：**学习与复习是两类不同的活动**，不再有「短期空间 / 长期空间」之分。所有学习空间都是学习空间，其 `new_study_type` 决定制卡倾向：

- **默认**——按 ADR-0009 的门槛制卡：只从真实失败点产生。
- **禁止制卡**——全程不触发制卡。用于用户明确「这次只是想了解一下，忘了就忘了」。
- **激进制卡**——用户主动声明这块内容需要长期保持，制卡判据放宽、频率提高。

复习不是空间（见 ADR-0010），而是独立的会话类型，按 Topic 选取到期卡。

## 与被取代模型的差异

- ADR-0002 中「短期学习升级为长期」的迁移流程不再需要。卡片从一开始就归属 Topic 而非空间（ADR-0010），不存在「困在短期空间里需要搬出来」的情况。用户若中途认为某个空间的内容值得长期保持，改 `new_study_type` 即可，无需迁移任何数据。
- ADR-0002 关于「不支持长期降级为短期」的约束随之失效——`new_study_type` 三个值之间可以自由切换，它只影响此后的制卡行为，不影响已产生的卡片。

## 保留自 ADR-0002 的判断

制卡倾向仍挂在**空间**而非单场会话上：同一件学习任务下的每场对话应受同样的制卡约束，否则用户每开一场会话都要重新决策一次。

## 复习会话也可制卡，但须克制

复习会话不归属任何学习空间，因此查不到 `new_study_type`。它仍然可以制卡，且不受制卡倾向约束——用户既然在复习这块内容，说明它本来就是要长期保持的，此时发现新盲点是好事，不该被阻断。

但判据比学习会话更严：**只有在复习中暴露出新问题、或由当前卡片引伸出新知识时才制卡**。复习的本意是巩固已有卡片，不是借机扩张卡片集。这条是提示词约束而非硬规则，因为「克制」本身是判断，无法表达成布尔条件。

典型场景：复习「Java 内存模型」时答错，讲解过程中发现用户对 `happens-before` 毫无概念——这值得单独成卡。而仅仅是把原卡答对了，不构成制卡理由。

## Consequences

- 判断学习会话是否制卡只看所属空间的 `new_study_type`，判断点唯一。
- 「禁止制卡」是硬开关，必须在工具层拒绝，而非仅靠提示词约束模型。
- 激进制卡模式下卡片数量会明显上升，这是用户主动选择的结果，不属于 ADR-0009 要防的失控。
- 复习会话制卡时，新卡的 Topic 大概率就是当前复习的 Topic，但仍走 ADR-0010 的归类流程，不直接继承。
