# 内容默认 Markdown，图表优先 DSL，生图只做记忆锚点

学习内容默认以 Markdown 输出：生成成本低、适合流式展示、便于保存检索与版本化。完整 HTML 会显著增加模型输出量与 Token 成本，还带来服务端渲染与安全处理负担，因此作为后续可选能力，不进首版默认路径。

视觉产物按用途分工，二者并存而非互相替代：流程、时序、状态等有明确结构关系的内容，用 Mermaid 或其他可验证的图表 DSL；只有具象对象和视觉记忆锚点（例如背单词时的实物图）才使用 AI 生图。

## Consequences

- 生图是可选项，不是每个知识点都要配图；其费用、等待时间和失败处理需要在产品中明确暴露给用户。
- 不要用生图去画架构图、流程图——扩散模型产出的结构图不可验证也不可编辑，这是明确的反模式。
- 采用 HTML 输出前，需要先有服务端渲染与内容安全方案。
